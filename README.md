# Week 3 — Baseline Regression Pipeline (House Prices)

## Files

- `regression_baseline.py` — runnable leakage-safe training and evaluation script.
- `MODEL_COMPARISON.md` — report template populated with metrics when the script runs.
- `model_metrics.csv` — generated by the script with the test-set metrics.

## Run it

1. Put the cleaned Task 1 CSV in your repository (for example, `data/cleaned_house_prices.csv`).
2. Install dependencies:

   ```bash
   python -m pip install pandas numpy scikit-learn tabulate
   ```

3. Run:

   ```bash
   python regression_baseline.py data/cleaned_house_prices.csv
   ```

The CSV must contain `SalePrice`. If your dataset has a different filename or path, pass that path instead.

## Validation and leakage prevention

The script splits raw `X` and `y` into training and test sets before fitting any imputer, encoder, or scaler. Numeric median imputation and standard scaling, plus categorical most-frequent imputation and one-hot encoding, live in a `ColumnTransformer` within each model pipeline. Pipelines are fit on training data and only applied to test data during evaluation. Unknown test categories are ignored safely.

The script compares a training-mean `DummyRegressor`, plain Linear Regression, Ridge at four alpha values by default, and log-target experiments for Linear Regression and the best-RMSE Ridge alpha. It reports MAE, RMSE, and R² on the original target scale.
